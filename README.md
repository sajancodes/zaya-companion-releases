# Zaya Companion updates

Official Android app updates for Zaya, created and developed by Sajan Rai.

Download **Zaya-Companion.apk** from the [latest release](https://github.com/sajancodes/zaya-companion-releases/releases/latest).
The app checks this channel automatically and offers **Update now** when a new version is available.
Android asks for installation confirmation. Your app settings and pairing are preserved.

This repository contains public APK releases and update metadata only. The application source repository remains private.
